# TeamFlow Pro - Demo Walkthrough

Welcome to the TeamFlow Pro demo. This walkthrough highlights the core professional features of the application.

## 1. Executive Dashboard
- **Real-time Stats**: View the current state of all your projects at a glance.
- **Velocity Analytics**: Tracks task completion rates using interactive charts.
- **Allocation Insights**: Visualizes how tasks are distributed across statuses.

## 2. Project Portfolio
- **Workspace Management**: Create new projects with custom mission briefs and visual labels.
- **Team Expansion**: Add members to projects using verified email lookups.

## 3. High-Performance Kanban
- **Visual Flow**: Categorize tasks into 'To Do', 'In Progress', and 'Done'.
- **Drag & Drop**: Seamlessly move tasks between stages (powered by @hello-pangea/dnd).
- **Task Granularity**: Assign priorities, due dates, and owners to every objective.

## 4. Advanced Security
- **Role Enforcement**: Admins have full control; members can only update their assigned work.
- **Integrity**: Every action is verified against a strict set of database rules.

---

### Demo Interaction Script
1. **Login**: Authenticate using the premium Google login portal.
2. **Setup**: Create a new project called "Q3 Marketing Launch".
3. **Collaboration**: Invite a teammate (simulated by finding their email).
4. **Execution**: Create a task "Develop Campaign Assets" and set it to 'High' priority.
5. **Progression**: Move the task to 'In Progress' to see the real-time update in the dashboard charts.
